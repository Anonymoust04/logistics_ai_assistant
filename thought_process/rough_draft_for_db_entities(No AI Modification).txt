Data Entities for Logistics AI Assistant

NOTE: PK means Primary Key and FK means Foreign Key

Custom Data Types

Hub Type  - AIRPORT, PORT, OFFICE, SORTING CENTRE

status (For Delivery entity) - Waiting, Transporting, Arrived, Failed, Postponed

Address Type - 3rd Party Office, Hub, Home

------------------------------------------------------------------------------------------------
Raw Entities (O NF)

Parcel - parcel serial id, (sender (name, email, phone, address, postcode, country code), receiver (name, email, phone, address, postcode, country code)), weight, fragile

Hub - hub id, name, email, phone, hub type, address, postcode, unlocode

Staff - staff id, name, email, phone, hub id, role

Transport - Transportation ID, transportation type, registration date,

------------------------------------------------------------------------------------------------
(0 NF -> 1 NF) (Removing duplicated columns to ensure atomicity)
Parcel entity has 2 major duplicated rows (sender client and receiver client rows) which can be abstracted into Client Entity.

Client -  client id, name, email, phone, home address, postcode, country code

------------------------------------------------------------------------------------------------

(1 NF)

Parcel - parcel serial id, sender client id, receiver client id, weight, fragile

Client -  client id, name, email, phone, address, postcode, country code

Hub - hub id, name, email, phone, hub type, address, postcode, unlocode

Staff - staff id, name, email, phone, hub id, role

Transport - transportation id, transportation type, registration date

------------------------------------------------------------------------------------------------
(1 NF -> 2 NF) (Removing Partial Dependencies) (No non-key attribute should depend on only a part of a composite candidate key.)

Candidate Keys:
Parcel: parcel serial id
Primary Key: parcel serial id

Client: client id
Primary Key: client id

Hub: hub id
Primary Key: hub id

Staff: staff id
Primary Key: staff id

Transport: transportation id 
Primary Key: transportation id

There are no new entities created at this stage as all entities have single-column keys.

------------------------------------------------------------------------------------------------

(2 NF)

Parcel - parcel serial id (PK), sender client id (FK), receiver client id (FK), weight, fragile

Client -  client id (PK), name, email, phone, address, postcode, country code

Hub - hub id (PK), name, email, phone, hub type, address, postcode, unlocode

Transport - transportation id (PK), transportation type, registration date

Staff - staff id (PK), name, email, phone, hub id (FK), role

------------------------------------------------------------------------------------------------

(2 NF -> 3 NF) (No non-key attribute should depend on another non-key attribute)

There are no new entities created at this stage as all entities has no determining non-key columns.

------------------------------------------------------------------------------------------------

(3 NF)

Parcel - parcel serial id (PK), sender client id (FK), receiver client id (FK), weight, fragile

Client - client id (PK), name, email, phone, address, postcode, country code

Hub - hub id (PK), name, email, phone, hub type, address, postcode, unlocode

Transport - transportation id (PK), transportation type, registration date

Staff - staff id (PK), name, email, phone, hub id (FK), role 

------------------------------------------------------------------------------------------------

(For handling many to many relationships, M to N) 

Delivery - delivery id (PK), driver staff id, transportation id (FK), parcel serial id (FK), status, origin , destination, departure time, expected arrival time, actual arrival time (between parcel, transport and staff)

------------------------------------------------------------------------------------------------
(New Entities for Tracking)

Coordinates - transportation id (PK and FK), timestamp (PK), latitude, longitude,

Speed - transportation id (PK and FK), timestamp (PK), speed

Tracking event - event id (PK), parcel serial id (FK), delivery id (FK), timestamp
